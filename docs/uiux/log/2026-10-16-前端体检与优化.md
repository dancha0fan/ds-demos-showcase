# 2026-10-16 · 前端全面体检与 UI/UX 优化

> 范围：`frontend/`（Vue 3.5 + Vite 8 + Pinia + vue-router 4，mock 模式）。
> 方法：通读入口/路由/状态/主要页面与样式层 → 在 1440×810（桌面）与 390×844@2x（手机）下用 CDP 实测几何与截图 →
> 修复 → 全量门禁复跑。本文记**问题、严重度、改了什么、为什么、还剩什么**。

严重度口径：**P1** 主流程受损或大面积用户受影响；**P2** 明显的体验/正确性问题；**P3** 打磨项。

---

## 0. 结论速览

整体底子很好：设计系统有令牌、有门禁测试（物理/字号/间距/z-index/动效都被测试锁住），i18n 有完整性测试，
列表有请求代际防竞态（`gen.isCurrent`）、KeepAlive + 快照恢复、iframe 懒挂载、全局减弱动效闸门。
问题集中在四类：

1. **数据流串行化**：启动、登录态探测、首页、作品库都有"本可并行却逐个 await"的瀑布，导致首屏和每次换页白等往返。
2. **中文输入与交互细节**：全站 Enter 提交都绑在 `keyup.enter` 上，拼音选词的回车会直接触发搜索/提交——对中文站是 P1。
3. **布局与状态反馈**：移动端作品详情把预览推出首屏；筛选刷新时整格清空导致页面高度两次跳动；若干状态（错误、加载、未读）没有可见或可读的反馈。
4. **"写对了但没生效"的样式**：全站按下物理的 `transform` 因语法无效被浏览器整条丢弃；页面登场动画让页内 fixed 件错位。
   这类问题构建、类型检查、原有门禁全都看不见，只有在浏览器里读计算值才能发现。

本轮修复表内 **25 项**（P1 × 4、P2 × 17、P3 × 4），另有 8 项 P3 打磨；
§3 的 9 项决策项经确认后落地 5 项（B/C/D/E/H）、维持现状 3 项（A/F/G）、延后 1 项（I，须单独提交）。
合计 46 个已跟踪文件 +698/−255 行，新增 `src/utils/ime.ts` 与护栏测试 `tests/interactionGuards.test.ts`。

### 1.3 动效

| # | 严重度 | 问题 | 修法 |
|---|---|---|---|
| 13 | P2 | **换页先看一段回滚动画**：`html { scroll-behavior: smooth }` + `scrollBehavior` 返回 `{ top: 0 }` ⇒ 从长页底部跳转时，新页面从底部"滑"回顶部。且平滑滚动不受减弱动效约束。 | 换页与前进/后退一律 `behavior: 'instant'`；同页锚点保留平滑；`reset.css` 的平滑滚动包进 `prefers-reduced-motion: no-preference`。 |
| 14 | P2 | **跨页锚点失效**：首页 CTA `/about#sponsors` 的目标在 AboutView 数据回来后才渲染，路由滚动时元素不存在 ⇒ 落在页顶。 | `scrollBehavior` 改为 async，`waitForAnchor()` 用 rAF 轮询最多 3s，找到即落位（留 16px 呼吸）。实测落点 `top = 16px`。 |
| 15 | P2 | **打字机在后台空转、无视减弱动效**：首页在 KeepAlive 里，切走后定时器仍每 ~60ms 改一次响应式状态；减弱动效用户看到的仍是逐字闪动。 | `useTypewriter` 增加 `pause/resume`（保留字符位置），挂到 `onDeactivated/onActivated`；减弱动效时直接显示一句静态文案。 |
| 16 | P2 | **hero 主件自写 hover/active 物理，绕过 `.b-lift`**（违反 Rule 01：按下位移 4px ≠ 影偏移 8px，hover 影 10px ≠ ×1.5 档）。 | 改用 `.b-lift`，只声明 `--lift-sh / --lift-sh-hover / --lift-flat` 三个变量（8px 档）。**注意**：scoped 规则不能再写 `box-shadow`——它排在 `lift.css` 之后、特异度与库的 `:hover/:active` 相同，会把 hover 增影和按下清影一起盖掉。 |
| 17 | P3 | 卡片入场 `neo-fade-in` 0.5s，比令牌体系的页面级 250ms 慢一倍，网格多时拖沓。 | `.animate-in` 改用既有的 `b-rise-in` + `--b-dur-page` + `--b-ease-stamp`，删除冗余 keyframes。 |
| 21 | **P1** | **全站"按下压平"从未生效**。微交互库的 `:active` 写的是 `transform: translate(var(--lift-flat, var(--sh-off-md))) rotate(var(--tilt-press))`，而 `--sh-off-*` 是给 `box-shadow` 拼接用的空格分隔值 `4px 4px`——`translate()` 函数要求逗号，整条声明在计算期失效（= `none`）。结果：所有 `.btn` / `.tab` / `.tag-chip` / `.b-lift` 卡片按下时**只清影、不位移**，`--tilt-press` 的 -1° 也一起丢了；看起来是"影子闪没"而不是 Rule 01 的"压进表面"。`motion.css` 里 `.dv-rail/.dv-collapse/.uw-edit:active` 同病。实测"投稿作品"按钮强制 `:active`：`transform: none`。 | 位移改走**独立的 `translate` 属性**（接受空格分隔值），`transform` 只留倾斜；`translate` 加入过渡白名单，减弱动效分支同步清零。修后实测：`translate: 8px 8px` + `rotate(-1deg)` + 影清零（8px 档按钮位移 = 影偏移）。护栏：`translate()` 函数里出现 `--sh-off-*` / `--lift-flat` 即失败。 |
| 22 | P2 | **页面登场时页内浮动件错位**：登场动画给页面根加了 `transform`，这 250ms 里它成了页内 `position: fixed` 后代的包含块 ⇒ 首页论坛斜角 Tab 先按页面坐标画在 `top 705`，动画结束再跳回 `top 235`（每次回首页都闪一下）。详情页的收起竖轨、移动端动作栏同理。 | 新增 `.page-float` 标记：`.page-enter-active .page-float { visibility: hidden }`，登场期间不画、落定即现；三个常驻浮动件挂上标记。实测登场全程没有一帧在错误位置可见。 |
| 23 | P2 | **论坛斜角 Tab 的三处实现缺陷**（设计稿本身未动）：① 倾斜写在 `transform: rotate(-6deg)`，被 `.b-lift` 的 hover/active `transform` 整条替换 ⇒ 悬停时 Tab 摆正；② 滑出动画过渡的是 `right`（布局属性，每帧重排）；③ 移动端影写死 `3px … var(--ink)`，墨黑主题下 `--ink` 是暖白（同文件 T16 注释修过的同一类问题）。 | 倾斜改独立 `rotate` 属性（与库的 `transform` 叠加）；移动端走 `--lift-sh` 令牌（@720 的 `--sh-off-lg` 恰为 3px）并绑 `--text-forum`。滑出最初改成 `translate: -54px 0`，§3-C 落地时又改回过渡 `left`：锚定版心后"还藏着多少"随视口宽变化，`translate` 的 % 按自身宽解析算不出来（fixed 元素的 `left` 只重排它自己）。实测悬停：`rotate -6deg` 保留、hover 抬起 + 增影。 |

## 3. 决策项与结果

| # | 严重度 | 现象 | 决定与落地 |

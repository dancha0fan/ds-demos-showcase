# 提示词库本地验收

实现分支为 `feature/prompt-library`，基于 `5524f1d`。改动尚未提交或发布。

## 使用流程

1. 打开 `/prompts`，搜索标题或正文，按分类、是否已有作品筛选；支持按最新收录或作品数排序。
2. 打开详情页复制完整原文。没有作品的提示词也会保留在库中。
3. 登录后通过 `/prompts/new` 收录站外提示词，可填写分类和来源链接。投稿进入管理员审核收件箱。
4. 管理员在 `/admin?tab=inbox&filter=new_prompt` 核对全文和来源，批准后进入公开详情页。
5. 在详情点击“提交测试作品”。空白上传表单自动填入原文，已有草稿需要手动选择继续或填入。
6. 保留同一份第一轮原文上传作品，审核公开后出现在该提示词下。改动正文会形成另一条提示词。

正文仅规范 CRLF 换行和首尾空白，保留内部空白与大小写。模型、轮次和用时沿用作品已有记录；未填写的数据显示未知。同一句第一轮提示词不能保证后续追加输入、参考材料和人工调整相同。
